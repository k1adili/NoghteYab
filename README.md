# نقطه‌یاب (NoghteYab)

اپلیکیشن اندروید برای ذخیره فوق‌سریع موقعیت مکانی مغازه‌ها، فروشگاه‌ها و نقاط مورد نظر، به‌علاوه ضبط مسیر طی‌شده — با تمرکز روی سرعت و راحتی استفاده پشت فرمان.

## ویژگی‌ها
- نمایش زنده مختصات GPS
- **ویجت صفحه اصلی**: با یک لمس، موقعیت فعلی فوری ذخیره می‌شود و صفحه نام‌گذاری سبک (با ورودی صوتی + دسته‌بندی آماده) باز می‌شود
- دکمه افزودن نقطه از داخل خود اپ
- سرچ نقاط ذخیره‌شده بر اساس اسم یا دسته‌بندی
- ادیت نقاط: اسم، دسته‌بندی، و حتی مختصات (به سبک گوگل‌مپ، `Lat, Lng`)
- نگه‌داشتن روی هر نقطه → کپی مختصات
- ارسال مستقیم هر نقطه به Google Maps
- مدیریت دسته‌بندی‌های دلخواه از صفحه تنظیمات
- پشتیبان‌گیری و بازیابی به‌صورت فایل JSON (شامل نقاط و دسته‌بندی‌ها)
- **ضبط مسیر (Tracking)**: با روشن کردن سوییچ «ضبط مسیر»، مسیر طی‌شده ذخیره می‌شود؛ از صفحه «مسیرها» می‌توان هر مسیر را به‌صورت GPX یا KML خروجی گرفت و با هر اپی (Google Earth, Drive, تلگرام و غیره) به اشتراک گذاشت
- طراحی فارسی، راست‌به‌چپ، تم مشکی/سبزآبی، با فونت Vazirmatn

## قبل از build: فونت را اضافه کن
فایل‌های TTF فونت Vazirmatn را در مسیر زیر قرار بده (راهنمای کامل داخل همان پوشه):
```
app/src/main/res/font/
  vazirmatn_light.ttf
  vazirmatn_regular.ttf
  vazirmatn_medium.ttf
  vazirmatn_bold.ttf
```
دانلود از: https://github.com/rastikerdar/vazirmatn/releases

## نحوه استفاده از ویجت
۱. روی صفحه اصلی گوشی، ویجت «نقطه‌یاب» را اضافه کن.
۲. هر وقت به نقطه‌ای رسیدی، روی ویجت بزن — مختصات فوری ذخیره می‌شود.
۳. صفحه کوچک نام‌گذاری باز می‌شود؛ می‌تونی اسم رو تایپ کنی، بگی (دکمه میکروفون)، یا دسته‌بندی آماده انتخاب کنی. اگر عجله داری، دکمه «بعداً» را بزن — نقطه ذخیره شده و بعداً از داخل اپ می‌تونی ویرایشش کنی.

## نحوه استفاده از ضبط مسیر
۱. در صفحه اصلی، سوییچ «ضبط مسیر» را روشن کن.
۲. هر چند ثانیه یک‌بار موقعیتت ذخیره می‌شود تا زمانی که سوییچ را خاموش کنی.
۳. از آیکون «مسیرها» در نوار بالا، لیست مسیرهای ضبط‌شده (با تاریخ و مسافت طی‌شده) را ببین.
۴. روی هر مسیر دکمه GPX یا KML بزن تا فایل ساخته شده و صفحه اشتراک‌گذاری اندروید باز شود.

**نکته درباره Google Maps:** اپ موبایل Google Maps امکان باز کردن مستقیم یک فایل KML/GPX دلخواه و نمایش مسیرش را ندارد؛ این قابلیت فقط در Google Earth یا نسخه وب Google My Maps موجود است. فایل export‌شده را می‌توانی با Google Earth (در صورت نصب بودن) یا با آپلود به mymaps.google.com مشاهده کنی.

## Build با GitHub Actions
با هر push به شاخه `main` یا `master`، ورک‌فلو `.github/workflows/build-apk.yml` به‌صورت خودکار پروژه را build می‌کند و فایل APK را به‌عنوان Artifact در تب Actions قرار می‌دهد. همچنین می‌تونی از تب Actions به‌صورت دستی (workflow_dispatch) هم اجراش کنی.

## پشتیبان‌گیری
از صفحه تنظیمات، می‌تونی همه نقاط و دسته‌بندی‌ها را به یک فایل JSON export کنی یا از یک فایل قبلی import کنی (import رکوردها را اضافه می‌کند، جایگزین نمی‌کند). بک‌آپ‌های نسخه‌های قبلی اپ هم کامل سازگار هستند.
