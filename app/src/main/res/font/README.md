# فونت وزیرمتن

فایل‌های TTF فونت Vazirmatn را دقیقاً با همین نام‌ها در همین پوشه قرار بده (حروف کوچک، بدون فاصله):

- `vazirmatn_light.ttf`
- `vazirmatn_regular.ttf`
- `vazirmatn_medium.ttf`
- `vazirmatn_bold.ttf`

منبع دانلود رسمی: https://github.com/rastikerdar/vazirmatn/releases

نکته: اسم فایل‌های ریسورس اندروید فقط می‌تونه حروف کوچک انگلیسی، عدد و آندرلاین داشته باشه — پس دقیقاً همین نام‌ها رو استفاده کن.
